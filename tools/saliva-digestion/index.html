実験のスキル：試薬の反応

ヨウ素溶液 ― デンプンがあるか調べる

  • 青紫色になった → デンプンがある
  • 変化なし（うすい茶色のまま） → デンプンがない

ベネジクト溶液 ― 糖があるか調べる（加熱する）

  • 赤褐色になった → 麦芽糖などの糖がある
  • 青色のまま → 糖がない

ベネジクト溶液はデンプンとは反応しないが、麦芽糖やブドウ糖には反応する。これらの物質をふくむ液体にベネジクト溶液を加えて加熱すると、青色だったものが黄色や赤褐色に変化する。
